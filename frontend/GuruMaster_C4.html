Nivel 1
C4 Context — El sistema y su entorno

Muestra GuruMaster como una caja negra, sus usuarios directos y los sistemas externos con los que interactúa. Es el punto de partida para entender el alcance del sistema.

System(gurumaster, "GuruMaster Carga Colombia", "Copiloto de IA: consulta rentabilidad de viajes, costos operativos, normatividad colombiana (RNDC, Decreto 1079) y vencimientos de documentos de flota.") System_Ext(openai, "OpenAI API", "Modelo gpt-4o-mini para clasificación de intención, generación dinámica de SQL y respuestas en lenguaje natural colombiano.") Operador de FlotaUsuario del sistema. Propietario o administrador que consulta en lenguaje natural.
GuruMaster (Sistema)El sistema bajo diseño. Combina RAG documental + SQL + LLM en un solo endpoint.
OpenAI APISistema externo. Provee el modelo de lenguaje. Requiere OPENAI_API_KEY en .env.
